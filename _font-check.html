If a font says "not found":
  1. Gill Sans MT comes with Microsoft Office. Install / repair Office, or copy the file GIL_____.TTF (and GILB, GILI) into C:\Windows\Fonts.
  2. Futura Md BT ships with CorelDRAW and some older Office / Publisher installs — FUTURA_BT_MEDIUM or TTFUTURA_*.ttf. CorelDRAW is already on your machine, so look in its Fonts folder and install the ones you want.
  3. After installing, close and reopen this page (and the portfolio) so the browser picks them up.
  4. If they still do not appear, the section automatically falls back to Jost (Futura-like) and Cabin (Gill-like) from Google Fonts, so visitors never see a broken layout.
